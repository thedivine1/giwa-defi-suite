Tier B · the trust engine

DojangScore

A pure read layer: it composes four Dojang attestations into one number and four tiers. No state of its own about users — only a cache of owner-set manual scores for bootstrapping.

Composite · exact

How the 0–1000 is built

score(w) = min(1000, manual[w] || Σ active_weights)
// each attestation read is try/catch-wrapped —
// a missing / revoked proof degrades, never reverts

Tiers · downstream effect

One number, many gates

  • Unverified <200 · Silver 200–499 · Gold 500–799 · Platinum 800–1000.
  • tierOf() / tierName() are the only calls consumers need.
  • Account age is read from EAS getAttestation(uid).time — rewards wallets that aren't fresh/Sybil.
  • Graceful reads: every upstream call is wrapped, so a flaky attester degrades a score instead of bricking a query.
Extensibility · v2 design

Adding on-chain actions without redeploying the engine

  • Pluggable signal registry: a recordSignal(id, wallet, value) gated to a whitelist of signalReporter contracts (each protocol registers itself), each signal carrying a governance-set weight + decay half-life.
  • Composite becomes min(1000, baseAttestation + Σ decayed_signal_contributions) — so a wallet that swaps 5× and provides LP accrues "activity trust" that decays if it goes idle, resisting one-time farming.
  • Trust assumption added: reporters must be honest — mitigated by whitelist + per-signal caps + the attestation floor that already exists.
03
Tier C · the yield engine

WonVault

A standard ERC-4626 tokenized vault — which is the whole point: any wallet, aggregator or router integrates with zero custom code, and the accounting is audited library code, not hand-rolled.

Share-price engine

Yield = the price rising

sharePrice = (assets + virtualAssets) / (shares + virtualShares)
// yield enters as assets growing while shares stay flat
// → every existing share redeems for more
  • _decimalsOffset() = 18 injects virtual shares + assets — the inflation / first-depositor protection (Morpho · Euler v2 · OZ).
  • deposit() skims the tiered entry fee to treasury, then hands the net to super.deposit() so the share math is the library's, verbatim.
  • Testnet yield is simulated (open mint() into the vault) so the engine is visible on camera; mainnet removes the open mint and gates value through a role-controlled harvest().
The scar we ship with

The 1e21, told in three steps

① deposit minted 0 shares
With the offset off, an empty vault took the assets and issued no receipt — money in the box, ownerless.
② price → 1.09e+21
Trapped assets ÷ ~0 shares = astronomical. The "any shareholders?" guard saw supply 0 and refused, while 1194 TKRW sat inside.
③ redeploy + reader clamp
_decimalsOffset()=18 closes the rounding attack; the dashboard refuses to render an out-of-band price (— / "degraded") — defense-in-depth that caught it before real money.
04
Tier C · the trading floor

GIWASwap

Factory + Pool, constant-product, with the one feature no other chain can offer: the swap fee is a function of the swapper's trust tier.

Pricing · exact

x · y = k, trust-discounted

afterFee = amountIn * (10000 − feeBps) / 10000
amountOut = afterFee * rOut / (rIn + afterFee)
// require(amountOut >= amountOutMin) → slippage guard
  • Factory enforces A≠B, non-zero, no duplicate pair; canonical ordering token0 < token1.
  • Pool is itself the LP token (GLP); first mint locks sqrt(a·b) − 1000 permanently.
  • Reserves recompute from balances on every action — they cannot drift.
Why it can't be ported

The moat is the attester

  • feeBpsFor(swapper) reads DojangScore — needs Dojang + Upbit, which exist only on GIWA.
  • GIWA's ~200ms Flashblocks make the swap feel instant — a real UX edge on top of the fee edge.
  • The DEX's strategic role is foundational liquidity + price discovery + a verification flywheel, not just fee P&L.
