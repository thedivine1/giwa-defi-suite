DojangScore API — Quickstart

Integrate Proven trust data into your application.

Base URL: https://giwa-defi-suite.vercel.app

Authentication

All requests must include the x-proven-key header. Missing or invalid keys will return a 401 Unauthorized response.

Header format: x-proven-key: <your-key>

Note: Pilot keys are issued manually by the Proven team. Contact us or visit the app to request access.

Endpoints

Method Endpoint Response Shape
GET /api/score/{address} { address, score, tier, tierName, ceiling, ceilingProvenance, provenance{baseAttestation,trustlessState,reporterActivity,consentedProofs}, cached, usage }
GET /api/tier/{address} { address, tier, tierName, fees{swap, vaultEntry} }
GET /api/health { ok, chain, block }

Example Request

curl -s -H "x-proven-key: your-pilot-key" \
https://giwa-defi-suite.vercel.app/api/score/0xDe9De6f3d4a50BF414927EF6D523aFa65355492a
