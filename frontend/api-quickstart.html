Dojang Trust-Score API Quickstart

A thin, production-lean REST API for on-chain trust scores on GIWA Sepolia.

Base URL

https://your-deployment-url.vercel.app/api

Authentication

Include the x-proven-key header in all requests.

To get a pilot key, contact us via email or DM. Pilot tier includes 1,000 free calls per month. Paid tiers coming soon.

Endpoints

GET /api/score/:address

Retrieves the trust score and breakdown for a given wallet address.

Example Request

curl -H "x-proven-key: pilot_demo" https://your-deployment-url.vercel.app/api/score/0xDe9De6f3d4a50BF414927EF6D523aFa65355492a

GET /api/tier/:address

Retrieves the fee tier for a wallet.

Example Request

curl -H "x-proven-key: pilot_demo" https://your-deployment-url.vercel.app/api/tier/0xDe9De6f3d4a50BF414927EF6D523aFa65355492a

GET /api/health

Checks API and RPC health.

Example Request

curl -H "x-proven-key: pilot_demo" https://your-deployment-url.vercel.app/api/health
